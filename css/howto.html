CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan gaya dari halaman web. Dengan CSS, kita dapat mengubah warna, ukuran teks, jenis font, jarak antar elemen, hingga tata letak keseluruhan halaman agar terlihat lebih menarik
